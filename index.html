Stage 01 · Wire it right

Same circuit. Two very different engineers.

Both boards do the same job. Only one can be debugged in five minutes, handed to a teammate, or turned into a product. We teach the second one from day one.

01
Typical class result
  • Long jumpers looping off the board and over the laptop
  • No colour code, so power, ground and signal look alike
  • One bumped wire and the whole project stops working
  • Nobody else can follow it, not even the builder next week
How we teach it
  • Red for power, black for ground, a fixed colour for each signal
  • Power rails first, then short wires that lie flat on the board
  • Right-angle routes that never cross, so faults are easy to trace
  • Every module tested alone before it joins the build
